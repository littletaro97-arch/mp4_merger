# 媒体工具箱 v0.2.0

## 启动与迁移

推荐双击 `dist/MediaToolbox/MediaToolbox.exe`，没有命令行窗口。
复制到新电脑时必须复制整个 MediaToolbox 文件夹，不能只复制 exe。
便携包内含 Python 3.13、Tk 和 FFmpeg/ffprobe，不要求目标电脑安装这些依赖。
面向 Windows 10/11 x64；其它系统及旧版 Windows 尚未验收。
本机仅保留系统 PATH 的启动检查已通过，尚未在另一台无 Python 的全新电脑实测。

源码开发可双击 `启动程序.vbs`，需已安装 Python（含 Tk）；旧 bat 转发到此启动器，bat 本身仍可能闪一下，日常使用 exe 或 vbs。
状态写入源码目录的 automation_state.json；便携版状态写入 exe 同级。
便携文件夹须有写入权限，建议放个人文件夹，避免 Program Files。
迁移旧历史可在程序关闭后，将原 automation_state.json 复制到 exe 同级，旧目录路径需在新电脑重新选择。

## 现有功能

递归扫描选择的目录，每 10 秒检测一次。
同目录的 `XX.mp4` 和 `XX(1).mp4` 中，一份必须是纯视频，另一份必须是纯音频。
这是音视频轨道封装，不是两段视频首尾拼接；原规则保留，时长差及起始时间差上限 0.5 秒。
文件大小和修改时间稳定后，串行处理，校验后输出 `XX_merged.mp4`，保留源文件，不覆盖已有结果。
有 (2) 等额外编号时跳过。停止或关闭会等待当前文件处理结束（合并超时 300 秒），随后停止，不会重复启动工作线程。
日志仅显示最近约 1500 行；队列最多 2000 条，拥堵时丢弃新日志，防止长期监控无限增长。
历史已跳过项仍沿用原来的持久化规则，不会自动重试；源文件改动后如需重试，应先备份状态再检查对应 skipped 项。

## 扩展结构

- main.py：窗口、任务页、启动/停止、日志队列。
- tasks.py：PairMergeTask 服务，构造时注入状态、日志、工具路径、停止事件；run(directory) 为任务入口，不依赖 Tk。
- scanner.py：文件发现、配对及稳定性检测。
- media.py：工具发现、媒体探测、无损封装、输出校验；Windows 子进程禁用控制台。
- state.py：历史及任务状态，临时文件后原子替换写入。

新功能采用独立服务和独立任务页，沿用日志与生命周期；需要参数时在该页提供自己的控件。当前不引入动态插件框架，也不展示尚未实现的功能入口。

## 构建

开发电脑：Python 3.13 / PyInstaller 6.18.0，本地 ffmpeg/ 包含 ffmpeg.exe 和 ffprobe.exe。
运行 `powershell -ExecutionPolicy Bypass -File build.ps1`。输出为目录便携包，约 190 MiB，主要来自两个 FFmpeg 工具。
采用目录包，减少单文件版本每次启动的解压开销；无需增加运行时第三方 UI 依赖。

## 验证与资源结果

真实 720p、20 秒、约 18 MiB 样本：纯视频加纯音频合并通过，音视频流和输出时长校验通过，源文件保留，重复扫描不改写输出。
可重复运行 `python qa_check.py`；性能补充 `python qa_profile.py`（测试需要开发环境 psutil，生产不依赖）。样本和状态均使用临时目录，不访问用户监控目录。

本机短时采样（工作集，CPU 以一个逻辑核心为 100%）：

| 场景 | 峰值内存 | CPU | 测量说明 |
|---|---:|---:|---|
| 源码 GUI 监控 | 39.75 MiB | 1.36% | 8 秒，临时目录 |
| 便携 GUI 空闲 | 35.68 MiB | 1.23% | 5 秒，仅系统 PATH |
| FFmpeg 无节流 stream copy | 20.12 MiB | 55.79% | 10 次共 1.681 秒，平均 0.168 秒/次 |
| FFmpeg 以实时速度节流 | 24.04 MiB | 1.23% | 5 秒采样，仅诊断用途，生产未启用节流 |

GUI 和 FFmpeg 分别测量，表格不能直接当作全程联合峰值。样本不是大目录或数小时视频压力测试；CPU 峰值和耗时受磁盘、文件规模影响。
已有 stream copy 不解码重编码，避免大量 CPU；保留串行处理、日志上限、去重跳过通知，并把等待改为事件等待。没有证据需要限速，限速会延长任务。
新包 PE 子系统为 Windows GUI（2），Python DLL、Tk、FFmpeg 工具已包含；FFmpeg 工具与原文件 SHA-256 一致。
本次未做人工外观验收，也未宣称新电脑实机兼容性已通过。
